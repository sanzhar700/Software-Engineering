# User stories — Smart Campus study room booking

### US-01
**Story:** As a Student, I want to view room availability, so that I can find a free room for my study session.
**Priority:** High
**Assumption:** Availability information is provided for the requested time slot.

### US-02
**Story:** As a Student, I want to book a free room for a time slot, so that I can reserve it for individual or group study.
**Priority:** High
**Assumption:** The selected room is free and not blocked at the requested time.

### US-03
**Story:** As a Student, I want to cancel a booking I made, so that the reservation is released.
**Priority:** High
**Assumption:** The booking being cancelled was made by the Student.

### US-04
**Story:** As a Student, I want to receive a confirmation when I book or cancel a room, so that I know the action was recorded.
**Priority:** Medium
**Assumption:** The system sends confirmation for a booking or cancellation.

### US-05
**Story:** As an Administrator, I want to block a room, so that it cannot be booked while it is out of service.
**Priority:** High
**Assumption:** A blocked room cannot be booked.

### US-06
**Story:** As an Administrator, I want to unblock a room, so that it can become available for booking again.
**Priority:** High
**Assumption:** The room is currently blocked.

### US-07
**Story:** As an Administrator, I want to review room usage over a period, so that I can see how the study rooms are being used.
**Priority:** Medium
**Assumption:** Usage information is available for the selected period.
