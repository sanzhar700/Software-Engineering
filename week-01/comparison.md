## 6. Reflection (200–300 words)

The manual version took 103 minutes, while Rocket took 47 minutes to produce a working application. Rocket was faster because it created the interface and several extra features automatically, including charts, a student table and bulk import.

The main problem was that Rocket made assumptions that were not in the original requirements. It added 12 mock students, which made testing the four cases more difficult. It also initially rejected invalid values such as -5, 101, text and empty values, while the specification said they should simply be ignored. I fixed this with a follow-up prompt.

The manual version was much simpler and easier to control. I could directly connect each part of the program to the requirements and testing was straightforward. The Rocket version looked more complete, but it also contained more unnecessary complexity.

I would be more comfortable putting my name on the manual version because I understand its logic better. However, I would still use the AI version after checking and testing it properly.

The main thing I learned is that AI can make development faster, but it does not replace the software engineer. A human still has to understand the requirements, test the result, find defects and decide whether the generated software is actually correct.
